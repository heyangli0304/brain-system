### 模块3：TE隧道管理（核心：返回ODU类型+个数）
#### 3.1 创建OTN TE隧道
- **Method**：POST
- **Request-URL**：`/api/v1/actn/te/tunnel`
- **请求JSON**：
```json
{
  "tunnel-name": "tunnel-20260422-001",
  "source": "192.168.1.1",
  "destination": "192.168.2.2",
  "path-id": "PATH-001",
  "encoding": "ietf-te-types:lsp-encoding-oduk",
  "switching-type": "ietf-te-types:switching-otn",
  "provisioning-state": "ietf-te-types:tunnel-admin-state-up",
  "te-bandwidth": {
    "ietf-otn-tunnel:odu-type": "ietf-otn-types:prot-ODU4"
  },
  "protection": {"enable": true, "protection-type": "bidir-1-to-1"}
}
```
- **响应JSON**（**核心：返回ODU资源**）：
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "tunnel-name": "tunnel-20260422-001",
    "path-id": "PATH-001",
    "provisioning-state": "up",
    "operational-state": "up",
    "odu-resource-info": [
      {"odu-type": "ODU0", "available-count": 10, "bandwidth": "1.25G"},
      {"odu-type": "ODU4", "available-count": 1, "bandwidth": "100G"},
      {"odu-type": "ODUFlex", "available-count": 8, "bandwidth": "flex"}
    ],
    "create-time": "2026-04-22T10:00:00Z"
  }
}
```

#### 3.2 查询指定TE隧道
- **Method**：GET
- **Request-URL**：`/api/v1/actn/te/tunnel/{tunnel-name}`
- **请求JSON**：无
- **响应JSON**：同3.1创建响应

#### 3.3 删除TE隧道
- **Method**：DELETE
- **Request-URL**：`/api/v1/actn/te/tunnel/{tunnel-name}`
- **请求JSON**：无
- **响应JSON**：
```json
{"code":0,"message":"success","data":{"tunnel-name":"tunnel-20260422-001","status":"deleted"}}
```

## 第三部分：核心调用顺序（AI必须按此生成代码）
1. 启动服务：network_adapter → compute_adapter → orchestrator_service
2. 光网调度：查询拓扑 → 路径预计算 → 选择路径 → 创建TE隧道 → 获取ODU资源
3. 算力调度：获取Token → 查询集群资源 → 提交Proxy/Prefill/Decode作业
4. 监控：查询隧道状态 → 查询作业性能 → 异常触发回滚
5. 销毁：删除算力作业 → 删除TE隧道 → 释放ODUk资源

---

## 第四部分：核心函数清单（AI必须实现）
### 光网适配函数
1. `get_topology()` → 查询拓扑
2. `precompute_path(source, dest, odu_type)` → 路径预计算
3. `create_te_tunnel(tunnel_param)` → 创建隧道，返回ODU资源
4. `get_te_tunnel(tunnel_name)` → 查询隧道
5. `delete_te_tunnel(tunnel_name)` → 删除隧道

### 算力适配函数
1. `get_token(username, password)` → 获取认证
2. `get_cluster_resource()` → 查询集群资源
3. `submit_infer_job(job_param)` → 提交推理作业
4. `get_job_metrics(jobId)` → 查询作业监控

### 编排核心函数
1. `pd_deploy_workflow()` → P/D分离部署全流程
2. `full_rollback()` → 全链路回滚
3. `state_machine_update()` → 状态机管理
